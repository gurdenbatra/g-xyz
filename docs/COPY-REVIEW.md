# Copy review — drafted in your voice, for you to make yours

Every line below is a **draft**. I wrote them first-person, specific, and a
little rougher on purpose — smooth, balanced copy is the single biggest
"AI-made" tell. Read each one aloud; if it isn't how you'd say it, change it.
Each spot in the code is marked with `<!-- DRAFT (your voice) -->`.

Everything factual comes from your CV, LinkedIn, the projects, and this session.
Lines marked **⚠︎ flourish** are small voice touches I *inferred* — opinions or
jokes you haven't actually said. Keep, sharpen, or cut them.
